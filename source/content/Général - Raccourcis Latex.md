# Général
Des raccourcis généraux et très pratiques...
- `conote`: Citer une autre note avec un volet repliant (ne marche pas sur quartz à savoir pk, #todo)
- `$`: Permet d'en écrire deux, pour entrer dans un environment latex inline
- `Ctrl+$`: Crée un environment latex block

# Greek
Les lettres en grecques qui ne sont pas déjà là, ou certaines que je veux changer
- `@f`: $\varphi$, parce que bon, $\phi$ par défaut est pas ouf
- `@n`: $\nabla$
- `@N`: $\overrightarrow{\nabla}$
- `@c`: $\chi$
- `@L`: $\dot{\Delta}$, le laplacien tel que je le note ici

# Talking latex
De petits raccourcis pour écrire automatiquement les petits trucs usuels:
- `sa`: $,\;$, afin de faire un peu d'espace dans une expression (stand for such as)
- `frl`: $\forall$
- `then`: $\;\implies\;$
- `soit`: $\text{Soit }$
- `ie`: $\text{, i.e. }$
